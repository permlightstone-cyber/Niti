# Нити PWA v2

Первая веб-версия «Нитей»: кардиограмма жизни, физическая активность, шаги, тематические нити, события, люди, финансы, локальное сохранение и установка на главный экран Android.

Health Connect напрямую из обычной PWA не читается; для него позже нужен небольшой Android-мост/оболочка.

## v2

Исправлено сохранение форм и профиля, добавлена миграция старых локальных данных, manifest и service worker.


## Импорт финансов (v4)

На главном экране в панели «Финансы» нажмите «Импорт Excel / JSON».
Поддерживаются экспорты .xlsx с листами «Доходы», «Расходы», «Переводы»
(строка 2 — заголовки), а также .json схемы niti.finance.v1.
При повторном импорте записи затронутых месяцев заменяются; другие месяцы
и ручные финансовые события сохраняются.

Данные импортируются и сохраняются **только в localStorage браузера** на
устройстве, не коммитятся в этот публичный репозиторий и не отправляются на
сервер. Данные не синхронизируются между устройствами и исчезнут при очистке
данных сайта. Используйте «Скачать резервную копию». Это локальное хранение,
не шифрование: доступ к устройству/профилю браузера может открывать данные.
Для .xlsx нужен современный браузер с DecompressionStream('deflate-raw').

Сводка учитывает доходы и расходы в валюте учёта экспорта (TRY);
переводы между собственными счетами не включаются в результат. Суммы
по категориям и разница за месяц не являются остатком банковских счетов.
Финансовая линия отображает дневную разницу импортированных доходов
и расходов; при отсутствии точного времени операция визуализируется в
середине дня.
